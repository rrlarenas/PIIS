# Prior Work — Research Agenda

PIIS must establish a clear and testable contribution beyond earlier standardization efforts. Review, without presuming equivalence:

- Workflow Management Coalition / XPDL — exchanging workflow definitions.
- OASIS WS-BPEL 2.0 — executable service-process definitions.
- OMG BPMN 2.0 — notation, execution semantics and conformance.
- OMG Model Driven Architecture (MDA) — platform-independent and platform-specific models.
- OASIS Service Component Architecture — composition and bindings.
- CNCF Open Workflow Specification (formerly Serverless Workflow) — portable declarative workflows and conformance.
- Enterprise Integration Patterns — implementation-neutral integration vocabulary.
- IETF benchmarking methodologies — reproducibility and disclosure practices.

**Research question:** Which of these already address observable functional equivalence and portable migration across independently implemented integration engines, and what gap does PIIS demonstrably fill?

Do not present an absence of universal market adoption as proof that a capability has never been specified. Compare exact scope and conformance semantics before asserting novelty.
