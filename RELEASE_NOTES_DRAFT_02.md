# PIIS Working Draft 02 — Public Review

**Release name:** `PIIS Working Draft 02 — Public Review (ES/EN)`

## English

This inaugural public review release presents the **Portable Integration Interface Specification (PIIS)**: a proposed portable functional definition and observable contract for integration interfaces, independent of each engine's internal design.

PIIS explores migration without functional loss, verifiable conformance, and independent comparison of conforming implementations using **complete end-to-end outcomes**, conforming throughput, CPU, RAM, scalability, resilience, functional integrity, operational cost and migration effort.

**Included:** original Spanish Working Draft 02; full English translation; comprehensive project README; contribution guidelines; prior-work research agenda; benchmark/conformance notes; CC BY 4.0 license and citation/Zenodo metadata.

**Not claimed:** an adopted standard, universal execution equivalence, automatically portable proprietary code, a completed interoperability trial, or a certified plug-and-play migration.

**Next milestones:** public technical critique, systematic comparison with earlier standards, portable semantic model, independent conformance trials, and reproducible benchmarking.

## Español

Primera versión pública de revisión de la **Portable Integration Interface Specification (PIIS)**. Presenta la definición funcional portable y el contrato observable para interfaces de integración, con plena libertad de implementación interna.

El proyecto busca portabilidad funcional, conformidad verificable y comparación objetiva mediante resultados End-to-End completos, throughput conforme, CPU, RAM, escalabilidad, recuperación, integridad funcional, costos y esfuerzo real de migración.

**Incluye:** Draft 02 completo en español, traducción íntegra al inglés, README ampliado, reglas de contribución, antecedentes, metodología preliminar de evaluación y metadatos de citación.

**No constituye:** un estándar aprobado, un RFC ni una demostración de migración automática universal.
