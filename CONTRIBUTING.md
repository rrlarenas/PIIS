# Contributing to PIIS

PIIS welcomes technically grounded critique, comparison with prior specifications, counterexamples, proposed contract semantics and reproducible conformance scenarios.

Please open an Issue describing the problem, the affected draft section, an example and the expected observable effect. Proposals should distinguish facts, assumptions, implementation choices and verifiable claims. Vendor-neutral language is preferred.

**No implementation architecture is mandated.** Do not propose new rules for established HL7, FHIR, DICOM, HTTP(S), MQTT or other external standards.

## Contribution licensing

The initial documentation is CC BY 4.0. By contributing text in a pull request, you confirm that you have the right to submit it and agree that the contribution may be distributed under CC BY 4.0, with attribution through Git history. Do not submit confidential information, employer-owned material without permission or third-party material without the necessary rights.

This is a preliminary community contribution policy, not a final standards-development IP framework. Additional IP/patent policies must be evaluated before a formal submission to a standards body.
